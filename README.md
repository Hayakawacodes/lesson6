# 👋 自己紹介ページ

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

HTML と CSS だけで作った、シンプルな **自己紹介ページ** です。
プログラミング学習の一環として作成しました。

---

## 📖 プロジェクトの説明

名前・ひとこと・趣味・スキルを 1 枚のカードにまとめて紹介するページです。

### 主な内容

| セクション | 内容 |
| --- | --- |
| 👤 名前 | ページの一番上に大きく表示 |
| 💬 ひとこと | 簡単な自己紹介メッセージ |
| 🎮 趣味 | ゲーム・音楽・アニメ |
| 📊 スキル | HTML/CSS・JavaScript・AI活用 の習熟度をバーで表示 |
| 🖼️ 画像 | お気に入りの画像 |

### 工夫したポイント

- 🎨 **グラデーション背景**：濃い青から水色へのグラデーション
- ✨ **フェードインアニメーション**：ページを開くとカードが下からふわっと表示される
- 📈 **伸びるスキルバー**：カード表示後にスキルバーが左から伸びるアニメーション
- 🖱️ **ホバーエフェクト**：趣味の項目にマウスを乗せると色が変わる
- 📱 **スマホ対応**：画面幅に合わせてレイアウトが調整される
- 🔤 **Google Fonts**：日本語フォント「Noto Sans JP」を使用

---

## 🛠️ 使用技術

- **HTML5** - ページの構造
- **CSS3** - デザイン・レイアウト・アニメーション
  - Flexbox
  - `@keyframes` アニメーション
  - CSS 変数（カスタムプロパティ）
  - `:hover` 疑似クラス
